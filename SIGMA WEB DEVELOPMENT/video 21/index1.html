What is CSS?

CSS stands for Cascading Style Sheets. It is the language used to style HTML elements, control layout, add animations, change colors, and make websites look modern and interactive.

See Types

Why we use CSS

CSS helps us create beautiful web pages. It improves readability, adds responsiveness, supports animations, separates content from design, and lets developers style large websites much faster and more cleanly.

How CSS works

HTML defines the structure, while CSS gives the design. For example, CSS can set font size, margins, background colors, borders, hover effects, transitions, and animations.

Types of CSS

  • Inline CSS: written directly inside an HTML tag.
  • Internal CSS: written inside the style tag in the head section.
  • External CSS: written in a separate .css file and linked to HTML.

CSS in action

Modern websites use CSS for layout, spacing, and visual balance.

Parallax, glowing buttons, smooth scroll, and moving elements are all possible with CSS and JavaScript.

Who invented CSS?

Håkon Wium Lie is a Norwegian web pioneer and one of the key minds behind the creation of CSS. He first proposed the idea in 1994, helping shape how the web could be styled in a more structured and standards-based way.

In 2005, while serving as the Chief Technology Officer (CTO) of Opera Software, Lie proposed and co-created the Acid2 test. This visual browser test suite was designed as a challenge to Microsoft and to push Internet Explorer 7 toward proper compliance with open web styling standards.

The Acid2 test became a landmark moment because it encouraged the browser industry to align more closely with modern web standards, especially for layout, styling, and visual rendering.

How to create a CSS file

Create a file with the extension .css, write all styles inside it, and link it to your HTML page with the link tag.

<link rel="stylesheet" href="styles.css">

Important CSS Concepts

Selectors

Selectors choose which HTML elements should be styled, such as tags, classes, IDs, and pseudo-classes like hover.

Properties

Properties define what to change, including color, background, padding, margin, border, font-size, and animation.

Values

Values tell the browser how to apply the property, such as blue, 20px, center, or a rotating animation.

Simple CSS example

body {
  background-color: #f8fbff;
  color: #0f172a;
}

h1 {
  text-align: center;
  color: #2563eb;
}

How to start using CSS

Step 1

Create an HTML page and add your content.

Step 2

Create a separate .css file and write your rules.

Step 3

Link that file in the HTML head using the link tag.
